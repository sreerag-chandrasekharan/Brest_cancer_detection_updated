# Breast Cancer Detection from Lab Results

## Project Overview
This project explores the development of a machine learning model capable of predicting breast cancer type—benign or malignant—based on cytosis cell lab results. The goal is to provide an instant diagnostic prediction from a patient’s lab profile.

The next phase involves integrating mammography imaging datasets to assess cancer severity, creating a more comprehensive diagnostic tool.

**Try the model:** [Web App]([https://lnkd.in/eF2vFZZy](https://brestcancerdetection-o3o4mfhsfnrgltadyd93.streamlit.app/))

---

## Features
- Predict breast cancer type (benign or malignant) from lab results
- Web application for instant predictions
- Easily extendable to include imaging data for severity assessment

---

## Key Tools and Methods
- **Scikit-learn** – for model development
- **DVC (Data Version Control)** – for dataset and pipeline versioning
- **MLflow** – for experiment tracking and model management
